# Sea N Shore IT — snsit.co.in

Portfolio and services website for **Sea N Shore IT Solutions LLP**.

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `assets/brand/` — SNS IT logo files
- `assets/clients/` — client logos (white + original colour)
- `assets/work/` — desktop and mobile screenshots of live projects

## Deploy
Upload `index.html` and the `assets` folder to `public_html` on the hosting for snsit.co.in.

## Edit content
Projects, services, FAQ and testimonials live in the `<script>` near the bottom of `index.html`
(`WORK`, `SERVICES`, `FAQ`, `QUOTES`). Testimonials stay hidden until real quotes are added to `QUOTES`.
