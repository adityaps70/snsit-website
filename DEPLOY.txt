Sea N Shore IT — snsit.co.in
============================

Build:
  npm install
  npm run build          (creates the "out" folder)

Upload to Hostinger:
1. Open hPanel > Websites > snsit.co.in > File Manager > public_html
2. Remove the old index.html and assets folder
3. Upload everything INSIDE the "out" folder (keep the folder structure, including _next)
4. Visit https://snsit.co.in — enable free SSL in hPanel if it isn't on yet.

Edit content: components/site/content.ts (projects, logos, services, FAQ, contact details).
